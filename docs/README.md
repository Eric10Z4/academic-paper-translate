# Historical validation reports

These reports record tests performed on the versions named in each report.
They do not claim that every platform, paper, model, or subsequent change has
passed the same live translation checks.

Local machine paths have been replaced with installation-relative placeholders
for publication. Evidence archives mentioned in the reports were local acceptance
deliverables, not necessarily GitHub release assets. Private rollback archives
must not be published.

Use the root README and SKILL.md for current commands, configuration and limits.
Use VERSION for the current code version.
