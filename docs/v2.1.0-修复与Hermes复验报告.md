# 学术论文翻译 Skill 2.1.0 修复与 Hermes 复验报告

日期：2026 年 10 月 13 日。

**2.1.0 已部署到 Hermes 的 academic-paper-translate 技能目录。86 项确定性回归全部通过，7 个端到端场景全部达到预期，另一次 Hermes 日常命令行调用成功。** 本次解决 Bash 入口、常见安全无参宏、预存原文归档三项兼容性问题，并补上真实编译发现的宏与中文粘连问题。

安装目录：`<HERMES_SKILLS>/academic-paper-translate`。现有 CPA、模型和私人配置保留。用户原始论文与桌面规范未修改。

## 修复内容

| 问题 | 最终行为 |
| --- | --- |
| Hermes 终端是 Bash，示例却使用 PowerShell | SKILL.md 默认直接调用指定 Python，并设置 UTF-8；明确区分技能依赖环境与 Hermes 自身解释器。旧 run.ps1 仅保留兼容用途。真实 Hermes 终端记录证明未调用 PowerShell。 |
| 无害的格式化宏导致原生降级 | 根据定义递归检查无参宏，支持纯文字、常见字体包装、xspace、嵌套安全宏、简单 let 别名、无参 def/gdef 与受限 ensuremath。宏定义和调用仍保留在源码中，名称本身不构成白名单。 |
| 加白名单可能放过隐藏结构的宏 | 参数宏、递归、隐藏环境或输入、危险重定义等仍在模型调用前拒绝；保存所有遇到的定义，避免安全的局部重定义掩盖其他不安全定义。 |
| 模型删除宏后空格，生成如 `\eg中文字` 的非法控制词 | 回填时在冻结命令外补充必要的 TeX 分隔空格，防止与中文或拉丁字母粘连；不修改公式、引用或宏定义内部内容。 |
| 归档目录预存 original.pdf 被一概拒绝 | 原文与明确提供的输入 SHA-256 一致且是有效 PDF 时接纳；保留原文件内容和修改时间。其他笔记可保留，未登记译文和不匹配原文仍拒绝。 |
| 已登记工程续跑时重新生成英文 PDF 引发冲突 | 未变动的 TeX 输入复用已登记且散列验证通过的原文；原文被改动则拒绝。明确传入的 --original 也实际用于处理流程。 |

修改文件共 7 个：`SKILL.md`、`AUDIT_SPEC.md`、`VERSION`、`scripts/latex_syntax.py`、`scripts/zotero_translate.py`、`tests/run_acceptance.py`、新增 `tests/test_compatibility.py`。完整差异在测试证据包的 `runner/revision_changes.patch`。

所有实际模型翻译由 Hermes 启动技能，调用原有 CPA；修复后的复验允许复用此前真实译文缓存，缓存仍重新经过完整性校验，未手工替换译文。

上述各场景英文、中文、双语 PDF 均为 1 / 1 / 1 页。另让 Hermes 按 SKILL.md 的普通 Bash 命令直接调用 `zotero_translate.py --input ... --output-dir ... --workers 2 --no-fallback`：进程退出码为 0，状态为 complete_native，缓存命中 13，源码 ZIP 重编译成功。

独立检查了交付文件散列、PDF 页数与中文文本、占位符未泄漏、ZIP CRC，并渲染查看宏场景中文与双语页面、PDF 原地归档译文页面。所检查页面未发现表格、公式裁切或重叠。缩写仍保留英文，中文重排与语言自然度不等于完全对齐或免审。

同时对上一轮的 CVPR、NeurIPS、ICML、ACM、多页、xeCJK 和基础工程共 7 组输入做了只读解析复验，全部通过；本轮没有重做这些全部模板的模型翻译及整套编译，也没有完成历史 62 篇论文全文回归。

## 保留的失败证据

首轮真实验收中，宏识别和翻译成功，但模型删除分隔空格，造成宏与中文粘连，原生编译失败；对应的无降级测试如实返回 failed。修复后补充边界回归，并通过 Hermes 全量复验。首次失败日志、清单及未编译源码保存在证据包的 `validation/first_attempt`，没有删除失败来制造通过记录。

## 适用边界

- 仍是有明确支持范围的静态解析器，不执行任意 TeX 展开。复杂条件宏、未知正文环境、任意 sty/cls 内部定义等可能继续降级。
- 安全宏本身被冻结；藏在宏定义中的长段落不会自动翻译。不把宏兼容扩大解释为全文语义准确率 100%。
- 本次七个场景是可复现构造工程，不代表任意真实论文均通过。双语页码并排不保证逐段对应；PDF 降级不具备源码级冻结证明。
- MiKTeX 仍禁止编译期间自动安装宏包；缺包应按日志补齐。源码 ZIP 重编译证明针对当前机器环境，不保证另一台机器无需安装字体或宏包。
- 允许 PDF 在已有论文目录内归档；TeX 原工程根目录仍不作为输出目录，避免改写源工程。
