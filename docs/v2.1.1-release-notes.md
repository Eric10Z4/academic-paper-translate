# v2.1.1 repository and packaging corrections

This release aligns public instructions and packaging with the Hermes workflow.
It updates both READMEs, restores private-file exclusions, removes the unused
YAML example, fixes the companion downloader's obsolete CLI options, and replaces
machine-specific skill paths with configurable installation paths.

The wheel now uses the academic_paper_translate namespace, includes prompt and
version resources, and provides the paper-translate command. Source checkout
commands remain supported. VERSION and requirements.txt supply package metadata.
The pdf extra installs uv; PDF fallback still uses the existing pinned engine.

Local validation on Windows/Python 3.13:

- 86 deterministic regression tests passed.
- Source distribution and wheel built successfully.
- Artificial private configuration, environment files, logs and rollback archives
  were excluded from both distributions.
- Installed prompt resources, version metadata, external configuration, help and
  doctor commands passed checks outside the source tree.
- Both skill files and documentation command examples were validated.

CI repeats regression and packaging checks on Windows and Linux without live
translation credentials. This release did not rerun the seven live Hermes
translation scenarios; those remain the v2.1.0 evidence and are described in its
report. Translation protection, compilation and PDF fallback behavior are
unchanged apart from import compatibility and reported version metadata.

See SECURITY.md for exposed-credential handling. Correcting current files is not
equivalent to revoking credentials or erasing all historical copies.
