## 实际测试结果

所有真实翻译均由 **Hermes 加载技能并启动脚本** 完成，调用既有 CPA。确定性回归采用受控替身注入故障，不把它们当成真实模型翻译。最终编译复验复用了此前 Hermes 的真实翻译缓存，缓存仍经过相同完整性校验；没有用手工或虚构译文替换结果。

各成功产物的 SHA-256 与清单一致；PDF 可打开、中文可提取、无内部占位符泄漏；所有原生源码 ZIP 的 CRC 和重新编译通过。数值表格、跨文件行数据、数学片段保持字节一致。这里只把被验证的投影称为字节一致，不把整个中文 TeX 与英文 TeX 说成相同文件。

## 验收过程中的失败与修正记录

本报告没有把中途失败删去：首轮数学比较因测试读取方式把 CRLF 换行规范化而误报，随后改为原始字节比较；新增占位符边界回归发现一处原文标记碰撞检测缺口并修复。CVPR 初始测试工程漏载 hyperref，英文也无法编译，后按官方示例建立独立完整样本；ICML 补全测试作者元数据；多页样本调整了 booktabs 底线与 input 的位置，使原英文工程有效。旧样本及日志均保留，不是修改用户论文来规避验收。

ICML/ACM 的缺包曾导致真实失败；补装实际缺失的 MiKTeX 宏包和字体后重跑。安装镜像发生过 SSL 错误，改用 CTAN 镜像重试，安装日志保留。一次 Hermes 测试因前台执行时限留下未完成清单；已核对并只终止本次卡住的验收进程，改用后台任务和已验证缓存完成测试，没有操作用户其他 Hermes 会话。

## 是否达到原规范

**在明确支持的 LaTeX 结构和本次测试范围内，已达到核心工程要求：源码优先、冻结内容不交给模型修改、真实中文编译、引用收敛、完整双语、不丢源码、可追踪降级。**

以下原规范中的绝对说法仍不能诚实地判为无条件达标：

1. **任意论文的语义 100% 准确、零漏译。** 程序校验的是选中片段完整性、标记和冻结内容，不能证明模型每句语义绝对正确。没有完成历史 62 篇全文回归，也没有逐句人工评审所有长文；跨整篇论文的术语一致性仍可增加专门术语表及复核流程。
2. **翻译后版式逐像素、浮动位置和分页不变。** 中文长度与字形必然可能引起重排；本次已经实际出现 8 页变 6 页。保持模板结构和页面尺寸，不代表所有原行距、换行或字体字形都绝对相同。旧字体的兼容映射会在编译记录中出现。
3. **任意 TeX 宏都可安全自动翻译。** 动态 input、未知带文本参数宏、未知环境、非 UTF-8 源码等采取明确失败或降级。遇到新模板应增加显式规则及回归，不能静默跳过并宣称全文完整。
4. **PDF 降级也能保证表格/公式字节冻结。** 降级已关闭表格文字翻译并启用图表保护，但依赖版面识别，无法达到源码级证明。它提供有标记的可读译文，不被包装成原生保真成功。
5. **无源码仍交付真实 TeX ZIP、无官方 PDF 仍交付官方原文。** 无源码时不伪造 ZIP；仅有 TeX 时对照 PDF 由未翻译源码在工作副本编译，并标明来源。用户提供的 PDF 则保留原始文件。

因此，修复版可以按本报告的范围在 Hermes 中使用；不建议把“complete_native”解读为无需检查任何真实论文的通行证。`review_required` 的文件已生成，但需要根据清单里的具体排版问题核查。
